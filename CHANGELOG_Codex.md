# Codex Change Log

This file records project changes made through Codex conversations so future sessions can quickly understand what changed and why.

## How to Use

- Add one entry for every meaningful code, config, documentation, or asset change.
- Keep entries concise: date, request, files changed, summary, verification, and notes.
- Use Asia/Shanghai dates unless a task explicitly needs another timezone.
- Do not replace old entries; append new entries at the top under "Entries".

## Entry Template

```md
### YYYY-MM-DD HH:mm CST - Short title

- Request: ...
- Files changed: ...
- Summary: ...
- Verification: ...
- Notes: ...
```
